def Knapsack(W, val, weights, n):
    dp = [[0 for _ in range(W+1)] for _ in range(n+1)]
    for i in range(1, n+1):
        for w in range(1, W+1):
            if weights[i-1] <= w:
                dp[i][w] = max(dp[i-1][w], val[i-1]+dp[i-1][w-weights[i-1]])
            else:
                dp[i-1][w]
    selected = []
    w = W
    for i in range(n, 0, -1):
        if dp[i][w] != dp[i-1][w]:
            selected.append(i)
            w -= weights[i-1]

    print("DP Table -:")
    for row in dp:
        print(row)
    print("Max value = ", dp[n][W])
    print(selected[::-1])

#     1. What is the Knapsack Problem?
# Imagine you have a bag (knapsack) with a maximum capacity of 5 kg.

# You have 3 objects:
# Object	Value	Weight
# 1	60	1 kg
# 2	100	2 kg
# 3	120	3 kg

# Your task is to select objects so that:
# - Total weight does not exceed 5 kg.
# - Total value is maximum.
# For this example:
# - Object 1 + Object 2 = Value 160, Weight 3.
# - Object 1 + Object 3 = Value 180, Weight 4.
# - Object 2 + Object 3 = Value 220, Weight 5.
# Maximum value = 220
# So, we select objects 2 and 3.
# 2. Logic of 0/1 Knapsack
# There are two choices for every object:
# 1. Include the object.
# 2. Exclude the object.
# Why is it called 0/1 Knapsack?
# - 0 means don't select the object.
# - 1 means select the object.
# You cannot take half an object.

# We use Dynamic Programming (DP) to solve this problem.

# The main formula is:
# \[
# DP[i][w] = \max(\text{Exclude},\text{Include})
# \]

# Where:
# - Exclude = dp[i-1][w]
# - Include = value + dp[i-1][w-weight]
# If the object's weight is greater than the current capacity, we cannot include it.

# 5. Understanding the DP table
# Let's understand how the table is created.

# Initially, the table contains zeros.
# [0, 0, 0, 0, 0, 0]


# Step 1: Select object 1 (value 60, weight 1).
# [0, 60, 60, 60, 60, 60]


# Step 2: Select object 2 (value 100, weight 2).

# At capacity 3, we can select object 1 and object 2.

# Value = 60 + 100 = 160.
# [0, 60, 100, 160, 160, 160]


# Step 3: Select object 3 (value 120, weight 3).

# At capacity 5, we can select object 2 and object 3.

# Value = 100 + 120 = 220.
# [0, 60, 100, 160, 180, 220]


# Therefore, maximum value = 220.

# 7. Important viva questions
# Question	Answer
# What is Knapsack Problem?	Selecting objects to maximize value within a given capacity.
# Which technique is used?	Dynamic Programming.
# What is 0/1 Knapsack?	Each object is either selected or not selected.
# Why is it called 0/1?	0 means exclude, 1 means include.
# What is DP?	Dynamic Programming solves problems by storing results of smaller subproblems.
# What is a DP table?	A table that stores previously calculated results.
# What is the base condition?	Zero objects or zero capacity gives value 0.
# Can we take half an object?	No.
# What is the time complexity?	O(n × W).
# What is the space complexity?	O(n × W).
# What is the difference between fractional and 0/1 Knapsack?	Fractional allows taking parts; 0/1 does not.

# 8. Most important points to remember for your practical
# 1. Knapsack is an optimization problem.
# 2. It uses Dynamic Programming.
# 3. We create a 2D DP table.
# 4. Every object has two choices: include or exclude.
# 5. We use max() to select the better choice.
# 6. Finally, we backtrack to find selected objects.
